Replica · design stage · concepts before build

A console that looks as cold and precise as the name. Nothing goes quietly green.

Everything below is rendered from the real token file (dark-first, light mirrored, every text pair passes WCAG AA). Pick a mark, pick a type pairing, flag anything that feels off, and the same tokens become the shipped CSS.

What to decide
  1. Mark — M1, M2 or M3
  2. Type pairing — A (HUD) or B (soft)
  3. Palette — keep, or steer a hue
  4. Density — the fleet table as shown, or tighter
  5. Anything in the five mocks that reads wrong

1 · Mark

Three directions, all original geometry, all legible at 16 px. The ice crystal is the shared idea: six axes, one centre, data frozen in place.

M1 Hex crystal

A hexagon cell with a six-spoke crystal inside. Reads as "storage cell" and "snowflake" at once; the strongest favicon of the three.

CRYOBACKUP

M2 Faceted shard

A single shard of ice, faceted like a cut stone, shield-shaped. More "vault", more premium; the facets flatten at 16 px into a plain shield.

CRYOBACKUP

M3 Cryo cell

A rounded pod with the crystal's six nodes dotted like a cluster diagram: one centre, six devices. The friendliest of the three; closest to a modern app icon.

CRYOBACKUP

The wordmark sets CRYO in ice blue and BACKUP in frost white; the short name "Cryo" stands alone in the tray and the agent. Tagline, used sparingly: Frozen in time. Back in seconds.

2 · Palette

Deep navy ground, ice-blue accent, frost-white type. Warm colours are reserved for state: amber warns, coral is critical, mint is healthy. Nothing else on the page is warm, so an alarm is the warmest thing in view.

4 · State language

Seventeen device states collapse into four visual classes. Shape carries the meaning as well as colour, so the board still reads for colour-blind operators and in print.

OK RUNNING 62% PENDING FIRST · 41h left DEFERRED · battery MISSED RUN PARTIAL · 23 files OUTDATED 1.3.0 ESCROW UNVERIFIED STALE 4d UNSEEN 9d FAILED ×3 BLANK · never backed up STUCK 76h UNKNOWN · facts unavailable IDENTITY CONFLICT MISSING CUSTOMER PARKED · until Fri 18:00 RETIRED
Mint dot — healthy. The only green on the page.
Ice square — informational and in progress. Never counts as healthy.
Amber triangle — warning. Early signal; becomes critical on its own if ignored.
Coral diamond — critical. Alarms, notifies, and sits at the top of every list.
Hollow ring — intentionally out of service (parked, retired). Listed, never hidden.
Pulse — a live run. Reduced-motion users see a static square.

Icon states

The tray icon is the mark, tinted by state. Users learn one glyph; the colour tells the story.

"Restore my files" opens a minimal local wizard (snapshot → folder → destination). Everything else is read-only. A user cannot change schedule, selection or retention from the endpoint; a technician can, from the console, with an audit entry.

Tone

Plain, specific, calm. "Backed up today at 02:10." Never "Your data is safe!" Errors say what happened and what happens next: "Waiting for power — will back up when plugged in, or at 18:00 at the latest."

10 · Decisions

Reply with the letters and anything to change. Each has a recommendation; none blocks the build of the state engine, which has no UI.

Mark
M1 hex crystal · M2 faceted shard · M3 cryo cell  → M1
Strongest at 16 px, works tinted as the tray icon, and the six-spoke crystal becomes a motif (loading spinner, empty states).
Type pairing
A Chakra Petch (HUD) · B Sora (soft)  → A
Matches "sci-fi, geeky" without tipping into gamer; used only for headings, the wordmark and big numbers.
Palette
Keep as shown, or steer: colder (more cyan), deeper navy, or a touch of violet in the ground.  → keep
Every pair already passes AA in both themes; a hue steer is a token edit, not a redesign.
Default theme
Dark by default, light as a per-user setting.  → dark
Density
Fleet table rows as shown (40 px), or compact (32 px) with the ten-day strip hidden until hover.  → as shown, with a compact toggle
Mocks
Anything in sections 5–9 that reads wrong, is missing, or you want to see before build (calendar matrix, policy editor, restore wizard, key reveal dialog are the next candidates).
