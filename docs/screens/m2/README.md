# M2 screenshot set

Every M0-M2 page and state of the console, rendered in **fixtures mode** (`cryo-console serve --fixtures`: the fictional
fleet, a frozen clock of Tue 20 Oct 2026 1:42 PM America/Chicago, no network). Nothing here is a real name, host, secret or
credential. Authenticator keys, QR codes, recovery codes, enrollment tokens and one-time links are blurred in the capture.

Each screen exists at 1360 px (desktop) and 390 px (mobile) in dark and light themes (the browser's colour scheme with the
console's System theme). File name: `<slug>.<width>.<theme>.png`. Pages taller than 3400 px are cut at 3400 px.

Method: a headless Chrome driven by a throw-away Playwright script (not part of the product). It starts
its own fixtures console per theme and width, signs in as the fixtures admin through the real MFA step, and visits each
route. The blurred areas hold fixtures-only values that vanish with the process. Pages not captured: 403 (needs a second,
lower-role account with its own MFA enrolment), restore progress and download (needs a live repository), the 503 "fleet
unavailable" fallback, and the cancel-run confirmation (a native browser dialog).
