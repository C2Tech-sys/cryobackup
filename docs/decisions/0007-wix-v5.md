# ADR 0007 - The MSI is built with WiX Toolset v5, pinned

**Date:** 2026-10-24 - **Status:** Accepted - **Decider:** operator

Complements ADR 0006 (MSI only), which did not name the toolchain.

## Decision

- The agent MSI is authored in WiX v4+ source format and built with **WiX Toolset 5.0.2**, installed as a pinned .NET tool (`dotnet tool install wix --version 5.0.2`, with the tool manifest committed so `dotnet tool restore` reproduces it).
- WiX 6 and later are not used: from 6.0 the project charges an Open Source Maintenance Fee to any organisation with more than USD 10 000 annual revenue that uses it, and 7.0 adds a EULA acceptance. That would bind every business that builds CryoBackup from source, not just the maintainer.
- WiX 5 is licensed under the Microsoft Reciprocal License (MS-RL) with no fee.

## Consequences

- WiX 5 receives no further fixes. MSI authoring is stable and the build input is our own `.wxs`; the move to a newer WiX (or another MSI builder) is a toolchain swap, recorded in a new ADR if it happens.
- Contributors need the .NET SDK to build the MSI; nothing else in the repo does.
