Where to get it

  1. Build it with make msi (output dist\windows\cryobackup-agent.msi) or take the signed MSI from your release channel.
  2. Copy it into the console's artifacts directory (the artifacts_dir setting) on the console host. This page then shows its hash. The console does not serve installers in this release and has no upload form, so nothing here is reachable from the internet.
  3. Stage the file on endpoints with your RMM's file distribution, and run install-cryobackup.ps1 with the variables from Enroll devices.

Agents reach the console at {{.ServerURL}}. A page that pre-binds a customer to a download arrives with release management.
