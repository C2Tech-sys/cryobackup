Retire {{.Retire.Host}} for good?

  • Revokes its device token now, and removes its gateway login from the gateway's file at the next sync, within seconds. If that sync fails, the console says so and a banner stays up until a read of the file finds the login gone.
  • Stops its maintenance, and it leaves every alarm and health count. If it is an expected customer's last active device, that customer reads MISSING, or ONBOARDING while its onboarding window is open.
  • Deletes nothing: the repository and its snapshots stay in storage. Restoring from a retired device is not available in the console yet.
  • Cannot be undone. Uninstall the agent from the machine: it keeps trying until you do. While an enrollment token is active, a recurring RMM script enrolls the same machine again as a new device, so stop the script or revoke the token.
One line. No file paths.
